projectmice-backup

projectmice-backup is a private, single-user backup tool. It copies encrypted backup archives made with restic to the owner's own Google Drive.

What it does

  • It uploads and reads only the files it created itself in the owner's Google Drive (Google scope drive.file).
  • Everything is encrypted with restic before upload. Google Drive receives ciphertext only.
  • It does not read, list or change any other Drive files, and it does not access Gmail, contacts, calendar or any other Google data.

It is not offered to the public. The only user is the owner.
