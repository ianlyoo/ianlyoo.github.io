Privacy policy: projectmice-backup

Last updated: 2026-10-11

Data accessed

The app uses only the Google Drive drive.file scope. That scope lets it create files in the owner's Google Drive and then read, update and delete only those files. It cannot see any other file.

Data stored

The files are restic backup repository data. It is encrypted on the owner's own machines before upload. Neither Google nor anyone without the owner's restic key can read the contents.

Use and sharing

The data is used only to store and restore the owner's backups. Nothing is sold, shared with third parties, used for advertising or used to train models. No analytics or tracking are used.

Retention and deletion

Backups stay until the owner removes them. Revoking the app's access at Google Account permissions stops all access immediately. Deleting the backup folder in Drive removes the data.

Google API Services User Data Policy

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
